# Horizontal scroll and all-device responsive fix

This build adds a final Bootstrap-breakpoint responsive layer that:

- prevents body/page-level horizontal sliding;
- contains the closed mobile and portal off-canvas menus;
- converts booking progress to a five-column responsive grid;
- wraps account navigation instead of using a sideways scroller;
- scales service videos, cards, forms, charts and media to their containers;
- keeps wide data tables scrollable only inside their own panel;
- supports desktop, laptop, tablet, mobile and compact 320px screens.
