# Responsive Bootstrap Update

This release keeps the complete Node.js, Express, EJS and SQLite application intact while improving layouts for desktop, laptop, tablet and mobile devices.

## Added
- Bootstrap 5.3 CSS and JavaScript stored locally in `public/vendor/bootstrap/`
- Final Bootstrap-breakpoint media-query layer in `public/css/responsive-bootstrap.css`
- Responsive navigation drawer with outside-click, Escape-key and resize handling
- Responsive grids, media, forms, booking wizard, customer portal and administration pages
- Bootstrap responsive tables for management screens
- Small-screen overflow, touch-target and modal improvements

## Run
1. Install Node.js 22 or newer.
2. Run `npm start`, or double-click `START-RESPONSIVE.bat` on Windows.
3. Open `http://localhost:3000`.
